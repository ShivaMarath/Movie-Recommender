# 🎬 Movie Recommender System

A machine learning-based movie recommendation system that suggests movies to users based on their preferences and similarity between movies.

## 🚀 Features

- Recommend movies based on a selected movie
- Content-based filtering using movie metadata
- Fast similarity search
- User-friendly interface
- Displays top recommended movies

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit (optional)
- Pickle


## 📊 Dataset

This project uses the TMDB 5000 Movie Dataset containing:

- Movie titles
- Genres
- Cast
- Crew
- Keywords
- Overview

Dataset Source:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
